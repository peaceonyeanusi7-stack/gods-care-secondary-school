# God's Care Secondary School — Website Demo

This is a frontend website concept prepared for a cold pitch to God's Care Secondary School, Enugu.

## Confirmed information taken from the provided school banner

- School: God's Care Secondary School, Enugu
- Motto: Knowledge is Light
- Address: 6 Ugbo Street, off Ubaka Gate, Achara Layout, Enugu
- Phone: 09041104816
- Banner mentions admission into JSS1 and JSS2.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Create a GitHub repository and upload this project.
2. Import the repository into Vercel.
3. Vercel should detect Vite automatically.
4. Deploy.

## Before presenting as the school's official website

Ask the school to confirm or provide:
- official logo file
- official phone/WhatsApp number
- school email
- exact address
- school history
- principal/proprietor details
- official academic programmes/subjects
- current admission information
- school photos
- official social media links

The current text is deliberately written as a concept where details were not available.
